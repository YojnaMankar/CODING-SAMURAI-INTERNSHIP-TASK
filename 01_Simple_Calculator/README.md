# 🧮 Simple Calculator

A basic command-line calculator developed using Python.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- User-friendly menu
- Handles invalid choices
- Prevents division by zero

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

Open the terminal in this folder and run:

```bash
python calculator.py
